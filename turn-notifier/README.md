# 提示铃（Chime）

智能体需要你注意时响铃提醒的 dsh 插件：任一会话答完一轮，或停下来等你操作（审批 / 提问）时响铃；不理会会按间隔重复，你一动鼠标、键盘或滚轮就停止。

## 功能

- **答完一轮**：任一会话的 `running` 由 `true` 变为 `false` 时响铃；如果该会话还有正在工作的子 agent，这次结束只是等待，不响（子 agent 自己的完成也不会单独响；它完成后会唤醒主会话继续）。
- **需要你操作**：任一会话（含子 agent）出现 `pendingInteraction` 时响铃。
- **后台会话也会响**：不只当前正在看的会话；切到插件页或设置页时也照常提醒。
- **重复与停止**：每次提醒先响一声，再按设定间隔重复，直到响满设定次数。鼠标移动、点击、按键、滚轮都会取消剩余次数；触发原因消失时也会停。
- **多会话合并**：「需要你操作」比「答完一轮」优先；同时或相邻到达的提醒会并进当前正在响的那一个，不会叠加轰炸。

## 铃声

每套铃声 = 一种音色 + 两段旋律：「答完一轮」落在和弦主音上，「需要你操作」停在和弦外的一个音上。

| 铃声 | 音色 | 答完一轮 | 需要你操作 |
|---|---|---|---|
| 音乐盒 | 音乐盒 | C6 E6 G6 C7 上行琶音 | G6 E6 G6 A6 |
| 马林巴 | 马林巴 | C5 E5 G5 C6 | C6 A5 C6 D6 |
| 拇指琴 | 拇指琴 | D5 F♯5 A5 D6 | A5 F♯5 A5 B5 |
| 电钢琴 | 电钢琴 | Cmaj7 分解和弦 | G5 A5 C6 D6 |
| 门铃 | 钟 | G5 → C5（叮—咚） | E5 G5 A5 |
| 颂钵 | 颂钵 | A4 一击长鸣 | D5 两击 |
| 经典 · 清脆（默认） | 经典 | `880:170, 1318.5:300` | `1046.5:140, 1318.5:140, 1046.5:200` |
| 经典 · 柔和 / 沉稳 / 单音 | 经典 | 配置页可选 | 配置页可选 |

音调写法是 **`频率Hz:时长ms`**，逗号分隔、按顺序播放；时长可省略（默认 200ms）。所有声音都在浏览器里实时合成，不需要音频文件。

## 配置

十项配置都在设置页里，改完立即生效：

| 字段 | 默认值 | 取值范围 | 说明 |
|---|---|---|---|
| `muted` | `false` | 真/假 | 静音，只让铃不响，其它设置不受影响 |
| `notifyOnTurnEnd` | `true` | 真/假 | 答完一轮时响 |
| `notifyOnWaiting` | `true` | 真/假 | 停下来等你操作时响 |
| `repeatCount` | `3` | 1–10 | 每次提醒响几声（含第一次） |
| `intervalMs` | `5000` | 1000–60000 | 两次之间的毫秒数，界面按秒显示 |
| `volume` | `1` | 0–2 | 音量；超过 1 的部分由输出限幅器兜住 |
| `voice` | `classic` | `classic` / `musicBox` / `marimba` / `kalimba` / `electricPiano` / `bell` / `bowl` | 音色 |
| `waveform` | `sine` | `sine` / `square` / `triangle` | 经典音色的波形 |
| `finishedPattern` | `880:170, 1318.5:300` | — | 答完一轮的音调 |
| `interactionPattern` | `1046.5:140, 1318.5:140, 1046.5:200` | — | 需要你操作的音调 |

### Plugins 页

打开 **Plugins（插件）页 → 展开本插件卡片 → 点开「提示铃」那一行（右侧 `›`）**：

- **什么时候响**：答完一轮 / 停下来等你操作 / 静音三个开关。
- **铃声**：选择提示音，旁边「试听」播放两段；选「自定义…」后展开音色、波形、两段音调面板。
- **音量与重复**：音量滑杆、响几声、间隔秒数。

拖动音量滑杆时只更新数字，松手才写入并试听；数字框和音调框失焦或回车提交；音调格式错误会标红并禁用试听；两段音调各有「恢复默认」。

### patch 配置

```yaml
- id: turn-notifier
  name: '@jedeiah/turn-notifier'
  config:
    repeatCount: 4
    intervalMs: 3000
    volume: 0.5
    waveform: 'triangle'
    finishedPattern: '660:120, 990:260'
```

## 安装与卸载

- **Plugins 页**：Add plugin，填 `github:Jedeiah/dsh-plugins#path:turn-notifier`，安装后启用。
- **`plugin_manager`**：`action: install_bundle`，`target: github:Jedeiah/dsh-plugins#path:turn-notifier`。
- **卸载**：Plugins 页 Remove，或 `plugin_manager` → `action: remove_bundle`，`target: @jedeiah/turn-notifier`。

## 兼容性

适配 dsh **0.2.2-rc.1**，不兼容更早版本。响铃与配置页都由本包提供，不需要额外运行环境。
